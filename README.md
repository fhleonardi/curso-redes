# Curso de Redes

Curso abierto de redes de computadoras en cinco módulos, con glosario. Cada módulo tiene teoría con ejemplos resueltos, laboratorios en [OpenRedLab](https://fhleonardi.github.io/openredlab/) y en Linux, un desafío sin guía, micro-logros y autoevaluación.

**Leelo online:** https://fhleonardi.github.io/curso-redes/

| Módulo | Tema |
|---|---|
| [1](https://fhleonardi.github.io/curso-redes/modulo-1.html) | Fundamentos de redes y capa física |
| [2](https://fhleonardi.github.io/curso-redes/modulo-2.html) | Modelos de referencia OSI y TCP/IP |
| [3](https://fhleonardi.github.io/curso-redes/modulo-3.html) | Direccionamiento IP, subnetting y enrutamiento |
| [4](https://fhleonardi.github.io/curso-redes/modulo-4.html) | Capa de transporte y aplicación |
| [5](https://fhleonardi.github.io/curso-redes/modulo-5.html) | Seguridad en redes, codificación segura y calidad de servicio |
| [Glosario](https://fhleonardi.github.io/curso-redes/glosario.html) | Términos con definición, ejemplos, errores frecuentes y fuentes |

## Qué hace falta

- Un navegador, para leer el curso y usar [OpenRedLab](https://fhleonardi.github.io/openredlab/).
- Para los laboratorios de Linux: una máquina virtual con Ubuntu Server (la portada explica cómo prepararla) y Wireshark en tu computadora.

Las páginas son archivos HTML independientes, sin servidor ni base de datos. Los micro-logros que tildás quedan guardados en tu navegador.
